Privacy

Questo sito è statico: non usa cookie, non ha moduli, non misura le visite e non carica script di terzi.

Applicazione collegata a Instagram

Per pubblicare i propri contenuti, l'autrice usa un'applicazione personale che si collega, tramite le API ufficiali di Meta, esclusivamente all'account Instagram @willfairywitch di cui è titolare. L'applicazione non raccoglie né conserva dati di altre persone: legge solo le statistiche aggregate dei propri contenuti. Il token di accesso è conservato in un file locale protetto, mai pubblicato.
